# Green Earth – Tree Plantation Store

A responsive tree plantation e-commerce style website where users can browse different categories of trees, view details, and add them to a cart.

## Features

- Browse trees by category (All Trees + dynamic categories from API)
- Beautiful tree cards with image, name, description, category, and price
- Add to Cart functionality with live total calculation
- Remove items from cart
- Tree details modal (name, image, category, price, description)
- Loading spinner while fetching data
- Fully responsive design (mobile + desktop)
- Campaign and impact sections
- Donation form section

## Tech Stack

- HTML5
- CSS3
- Tailwind CSS
- DaisyUI
- JavaScript (Vanilla)
- Font Awesome
- Programming Hero Open API

## Key Functionalities

- Dynamic category loading from API
- Dynamic tree cards rendering
- Cart management (add / remove / total price)
- Modal for detailed tree information
- Active category button highlighting
- Loading state management

## How to Run

Just open `index.html` in your browser.  
No build step required.
