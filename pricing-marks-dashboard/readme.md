\# Pricing \& Marks Dashboard



A React-based dashboard application that displays pricing plans and student marks visualization.



\## Features



\- Responsive pricing cards with popular plan highlighting

\- Dynamic pricing data fetched from JSON

\- Student marks chart using Axios

\- Result visualization component

\- Built with Tailwind CSS and DaisyUI for modern UI

\- Loading states handled with React Suspense



\## Tech Stack



\- React (Vite)

\- Tailwind CSS

\- DaisyUI

\- Axios

\- Lucide React (icons)



\## Project Structure



\- `PricingOptions` – Displays available pricing plans

\- `DaisyPricing` – Individual pricing card component

\- `MarksChart` – Visualizes student marks data

\- `ResultChart` – Additional result visualization

\- `NavVar` – Navigation component
